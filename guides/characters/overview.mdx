In Tavo, a character is a fully defined AI persona that governs how the AI presents itself, speaks, and behaves throughout your conversations. Every character is built from a set of fields — name, avatar, description, personality traits, first message, scenario, and more — that work together to give it a consistent identity. You can build a character from scratch or bring one in from an external platform using an import.

## What makes up a character

Each character you create or import in Tavo can contain the following:

| Field | Purpose |
|---|---|
| **Name** | The character's display name |
| **Avatar** | The profile image shown in chat |
| **Description** | Physical appearance, background, and key traits |
| **Personality** | Core personality descriptors that shape tone and behavior |
| **First message** | The opening line the character sends when a chat begins |
| **Scenario** | The setting or situation framing the conversation |
| **Dialogue examples** | Sample exchanges that teach the AI how the character talks |
| **Main Prompt** | A system-level instruction that overrides or extends the default behavior |
| **Post-History Instructions** | A reminder appended after each message to keep the character consistent |
| **Tags** | Keywords for organizing and identifying character types |
| **Creator Notes** | Author notes visible to users, not the AI |
| **Source** | Attribution link or author ID |

Not every field is required. A character can work with just a name, a description, and a first message — but the more detail you provide, the more consistently the AI will stay in character.

## How characters appear in the app

You access your characters by tapping the **Characters** button on the home screen or navigating to it from the **Menu**. From the character list you can start a chat, edit an existing character, or create a new one.

<Tip>
Your persona — who you are in the conversation — is a separate setting from the character. See [User Persona](/guides/characters/persona) to learn how to define your own identity and relationship to the characters you chat with.
</Tip>
