Tavo does not bundle an AI model — instead, it connects to the model provider of your choice using an API key that you supply. This design gives you full control over which model you use, how much you spend, and which provider you trust with your data.

The API setup process has four parts. Work through them in order the first time you set up Tavo.

## Supported providers

Tavo currently supports the following AI providers:

| Provider | Notes |
|---|---|
| **Volink** | Recommended for first-time users. Chinese-friendly payment options, no VPN required. |
| **Gemini** | Google AI Studio. Free tier available for personal Google accounts. |
| **Claude** | Anthropic. Requires a non-mainland-China phone number to register. |
| **DeepSeek** | Official DeepSeek platform. Top up account balance to unlock API calls. |
| **OpenAI** | ChatGPT platform API. Requires phone verification for the first API key. |
| **Doubao / Volcano / ByteDance** | ByteDance's model platform (火山方舟). Also carries DeepSeek models. Requires real-name verification. |
| **OpenRouter** | Aggregator with 200+ models from many providers. Good for comparing models. |
| **Custom (OpenAI-compatible)** | Any API endpoint that follows the OpenAI protocol, including local models. |

<Note>
  You need to register directly with your chosen provider and agree to their terms of service. Tavo does not resell API access — your key goes straight to the provider's servers.
</Note>

## How billing works

You pay the AI provider directly based on your usage (typically measured in tokens). Tavo itself does not charge per message. Check each provider's pricing page before you start, especially if you plan to have long conversations or use large context windows.
