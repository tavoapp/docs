Regex scripts in Tavo let you define find-and-replace rules that run automatically on messages. You write a regular expression that matches a text pattern, specify what to replace it with, and choose when and where the rule applies. This keeps your chat clean, consistently formatted, and free of unwanted artifacts — without you having to manually edit every message.

## Configuration fields

### Name

A human-readable label for the rule. It has no effect on the rule's behavior — it just helps you identify and manage rules when you have several.

```text
Name: Remove system prompt prefix
```

### Find Regex

The regular expression pattern to search for. The system scans messages for text that matches this pattern.

**Example — strip a `[System Prompt]:` prefix:**

```text
^\[System Prompt\]: (.+)$
```

Breaking this down:
- `^` — match at the start of the line
- `\[System Prompt\]` — match the literal text `[System Prompt]` (brackets are escaped because they have special meaning in regex)
- `: ` — match the colon and space
- `(.+)$` — capture everything after the prefix to the end of the line

### Replace With

The text to substitute in place of the matched content. Use `$1`, `$2`, etc. to reference capture groups from the regex pattern. Use `{{match}}` to reference the entire matched string.

```text
Replace With: $1
```

With the example regex above, this replaces the entire matched line with just the captured content after the prefix — so `[System Prompt]: Mission start` becomes `Mission start`.

| Placeholder | What it inserts |
|---|---|
| `$1`, `$2`, ... | The text captured by the first, second, ... group in the regex |
| `{{match}}` | The entire matched string, unchanged |

### Trim Out

Text to strip from the matched content *before* the replacement is applied. This is a simpler alternative to complex regex for removing a fixed prefix or suffix.

```text
Trim Out: Player says:
```

This removes every occurrence of `Player says:` from the matched text before further processing.

### Scope

Defines which types of messages the rule applies to. You can target any combination of:

| Scope | When it applies |
|---|---|
| **User messages** | Messages sent by you |
| **Character messages** | Messages generated by the AI character |
| **Chain of thought** | The AI's internal reasoning (if visible) |
| **Lorebook** | World book entry content |

```text
Scope: Character messages
```

### Timing

Controls at which point in the message lifecycle the rule runs:

| Timing | Description |
|---|---|
| **Display** | Runs when the message is about to be shown to you. The underlying stored message is unchanged. |
| **Send** | Runs when a message is sent to the AI. What the AI receives is modified; what you see is not. |
| **Send + Display** | Runs on both send and display. |
| **Receive** | Runs when a message arrives from the AI, before it is stored. |
| **Receive + Rewrite** | Runs on receive and also rewrites the stored message. |

<Note>
**Display** timing is the safest option for cosmetic cleanup — it only affects what you see, not what the AI or the message history contains. Use **Receive + Rewrite** when you want the cleaned version to persist in the chat history.
</Note>

### Substitution parameters

Controls how the replacement is applied:

| Parameter | Behavior |
|---|---|
| **No substitution** | No replacement is made; the match is left as-is. Useful for testing your regex. |
| **Literal replacement** | The replacement text is used exactly as written, preserving formatting. |
| **Escaped replacement** | Special characters in the replacement string are escaped before substitution, preventing unintended regex interpretation. |

## Complete example

**Goal:** Remove the `[System Prompt]:` prefix that appears at the start of certain character messages, keeping only the content that follows.

| Field | Value |
|---|---|
| Name | Remove system prompt prefix |
| Find Regex | `^\[System Prompt\]: (.+)$` |
| Replace With | `$1` |
| Trim Out | *(empty)* |
| Scope | Character messages |
| Timing | Display |
| Substitution | Literal replacement |

**Before:**
```text
[System Prompt]: The mission has begun. Your target is inside the warehouse.
```

**After:**
```text
The mission has begun. Your target is inside the warehouse.
```

## Practical uses

<AccordionGroup>
  <Accordion title="Strip unwanted prefixes or labels">
    AI models sometimes prepend labels like `Assistant:`, `AI:`, or `[OOC]` to their responses. A regex rule can strip these automatically before they reach your screen.

    ```text
    Find:    ^(Assistant|AI|Bot): (.+)$
    Replace: $2
    Scope:   Character messages
    Timing:  Display
    ```
  </Accordion>

  <Accordion title="Normalize formatting">
    If you want all em-dashes in character messages replaced with `—` (the proper Unicode character), or all asterisk-wrapped text reformatted:

    ```text
    Find:    \*\*(.+?)\*\*
    Replace: <strong>$1</strong>
    Scope:   Character messages
    Timing:  Display
    ```
  </Accordion>

  <Accordion title="Clean up user input before sending">
    If you use shorthand in your messages (like `/me` for actions), expand them before the AI sees your message:

    ```text
    Find:    ^\/me (.+)$
    Replace: *{{user}} $1*
    Scope:   User messages
    Timing:  Send
    ```
  </Accordion>

  <Accordion title="Extract and surface structured data">
    When using variable macros in game-like scenarios, regex can reformat status blocks that appear in AI responses into a cleaner display format.
  </Accordion>
</AccordionGroup>

<Warning>
Regex patterns that are too broad can accidentally match content you didn't intend to change. Always test a new rule on a few messages before applying it globally. Start with **Display** timing so the stored message history is not affected while you refine the pattern.
</Warning>
