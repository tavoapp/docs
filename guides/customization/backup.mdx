Tavo's backup feature lets you export a complete snapshot of your data — including API keys, character cards, chat history, and app settings — into a single backup file. You can restore from this file at any time, which is useful when switching devices, reinstalling the app, or recovering from data loss.

## Opening backup settings

<Steps>
  <Step title="Open the sidebar">
    Swipe right or tap the menu icon to open the left sidebar.
  </Step>
  <Step title="Tap More, then Settings">
    Tap **More** at the bottom of the sidebar, then select **Settings** from the expanded menu.
  </Step>
  <Step title="Select Backup & Restore">
    Inside Settings, tap the **Backup & Restore** tab.
  </Step>
</Steps>

## What is included in a backup

A Tavo backup file contains:

- **API keys** — all provider keys you have configured
- **Characters** — character cards, personas, and associated assets
- **Chat history** — your full conversation logs
- **Settings** — app configuration, theme selections, and preferences

<Warning>
  Because backup files contain your API keys, treat them like passwords. Store backup files in a secure location — such as an encrypted folder or a trusted cloud service — and do not share them with others.
</Warning>

## Creating a backup

<Steps>
  <Step title="Tap Create Backup">
    On the Backup & Restore screen, tap **Create Backup**.
  </Step>
  <Step title="Choose whether to include API keys">
    You will be prompted to choose whether the backup should include your API keys. Enable this option if you want a fully portable backup that can restore your entire configuration.
  </Step>
  <Step title="Save the backup file">
    Tavo generates a backup file and prompts you to save or share it. Save the file to a location you can access later, such as your device's local storage, iCloud, or another cloud service.
  </Step>
</Steps>

## Setting backup reminders

If you want to be reminded to back up on a regular schedule, you can configure a backup reminder:

<Steps>
  <Step title="Find the reminder setting">
    On the Backup & Restore screen, locate the **Backup Reminder** option.
  </Step>
  <Step title="Set a reminder interval">
    Choose how often you want to be reminded — for example, weekly or monthly. Tavo will send a local notification on that schedule prompting you to create a new backup.
  </Step>
</Steps>

## Restoring from a backup

<Steps>
  <Step title="Tap Restore Data">
    On the Backup & Restore screen, tap **Restore Data** (or **Import Backup**).
  </Step>
  <Step title="Select your backup file">
    Navigate to and select the backup file you previously saved. Tavo will read the file and apply the backup contents.
  </Step>
  <Step title="Confirm the restore">
    Confirm when prompted. The app will restore your characters, chat history, API keys, and settings to the state they were in when the backup was created.
  </Step>
</Steps>

<Note>
  **Version compatibility:** A backup created by a newer version of Tavo cannot be restored on an older version of the app. Before restoring, make sure the app is updated to at least the same version that was used to create the backup — ideally the latest available version.
</Note>
