Tavo lets you export any conversation to a local file and import chat history from a file. Exporting is useful for backing up conversations, sharing them, or moving them to another device. Importing lets you restore a conversation or bring in history from another chat platform.

## Export a conversation

<Steps>
  <Step title="Open the right sidebar">
    Inside the chat you want to export, tap the sidebar icon in the top-right corner of the screen.
  </Step>
  <Step title="Scroll to the bottom of the panel">
    Swipe down to the bottom of the sidebar panel.
  </Step>
  <Step title="Tap Export">
    Tap the **Export** button.
  </Step>
  <Step title="Choose a file format">
    In the dialog that appears, select the format you want:

    - **`.txt`** — Plain text, readable in any text editor.
    - **`.json`** — Structured data, suitable for processing or re-importing.

    Confirm your selection. The file is generated and saved to your device.
  </Step>
</Steps>

<Tip>
  If you plan to import the conversation back into Tavo later — on the same device or another — use the `.json` format for the most complete and accurate transfer.
</Tip>

---

## Import a conversation

You can import chat history that was exported from Tavo or from another compatible chat platform. Import files must use the `.jsonl` format.

<Steps>
  <Step title="Open the menu bar and tap +">
    Tap the menu icon on the left side of the screen to open the side panel, then tap the **+** button.
  </Step>
  <Step title="Select Import Chat History">
    In the menu that appears, tap **Import Chat History**.
  </Step>
  <Step title="Locate your file">
    Browse your device's file system and select the `.jsonl` file you want to import. If you are not sure where the file is, search your device for files with the `jsonl` extension.
  </Step>
  <Step title="Confirm the character assignment">
    After selecting the file, Tavo automatically tries to match the conversation to a character with the same name.

    - If a matching character is found, the import proceeds automatically.
    - If no matching character exists, you are prompted to manually select which character the conversation belongs to.

    Confirm your selection to complete the import.
  </Step>
</Steps>

<Note>
  Imported conversations appear in your chat list alongside your existing chats. The original file on your device is not modified or deleted.
</Note>

## Common use cases

<AccordionGroup>
  <Accordion title="Back up a conversation">
    Export the chat as a `.json` file and store it somewhere safe — a cloud drive, your computer, or an external device. If you ever lose access to the app or switch phones, you can import the file to restore the conversation.
  </Accordion>
  <Accordion title="Continue a conversation on another device">
    Export the chat from one device and transfer the file to another (for example, via AirDrop, email, or a shared drive). Import it on the second device, and your history will be available there.
  </Accordion>
  <Accordion title="Import history from another platform">
    If you have chat logs exported from a compatible platform in `.jsonl` format, you can import them into Tavo. Assign them to an existing character to continue the conversation from where you left off.
  </Accordion>
</AccordionGroup>
