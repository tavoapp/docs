description: "Open a conversation with any AI character in Tavo — select one from the character list on the home screen, use the menu bar, or create a fresh chat session."
---

Starting a chat in Tavo takes just a few taps. You can open a conversation directly from the character list on the home screen, through the menu bar, or by creating a new chat from scratch.

## From the home screen

<Steps>
  <Step title="Open the character list">
    Launch the Tavo app and tap **Characters** or **Start Chat** on the home screen.
  </Step>
  <Step title="Select a character">
    Browse your character list and tap the character you want to chat with.
  </Step>
  <Step title="Begin the conversation">
    The chat screen opens immediately. Type your first message and tap **Send** to start the conversation.
  </Step>
</Steps>

## From the menu bar

You can also start or resume a conversation directly from the left menu bar without going through the character list.

<Steps>
  <Step title="Open the menu bar">
    Tap the menu icon on the left side of the screen to open the side panel.
  </Step>
  <Step title="Choose a character or conversation">
    Tap a character name in the menu bar to jump straight into an existing conversation with that character. Alternatively, tap **Characters** to go to the character management page and select from there.
  </Step>
  <Step title="Start chatting">
    The conversation screen opens. Send your first message to begin.
  </Step>
</Steps>

## Create a new chat

If you want to start a fresh conversation with a character you have already spoken to before, you can create a new chat session without losing the existing one.

<Steps>
  <Step title="Open the menu bar">
    Tap the menu icon on the left side of the screen.
  </Step>
  <Step title="Tap the + button">
    Tap the **+** icon in the top-right corner of the menu bar.
  </Step>
  <Step title="Select the character">
    Choose the character you want to chat with. A new, empty conversation opens alongside any previous chats you have with that character.
  </Step>
</Steps>

<Tip>
  You can have multiple separate conversations with the same character. Each chat keeps its own history, so branching into a new session is a great way to explore different story directions without losing earlier exchanges.
</Tip>
