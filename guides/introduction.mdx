Tavo is a mobile app that lets you have immersive, personality-driven conversations with AI characters. Whether you want to import a ready-made character, build your own from scratch, or fine-tune how a character speaks and remembers — Tavo puts full creative control in your hands. You bring your own API key from a supported AI provider, and Tavo connects directly to the model of your choice.

## What you can do with Tavo

- **Chat with AI characters** — Start a conversation with any character in your library. Each character has its own persona, backstory, and voice.
- **Import and create characters** — Download character cards from the community or design a completely original character using Tavo's character editor.
- **Connect your own AI model** — Tavo works with OpenAI, Gemini, Claude, DeepSeek, Volink, Doubao, OpenRouter, IO Intelligence, and any OpenAI-compatible endpoint. You choose the model; Tavo handles the rest.
- **Shape your character's memory** — Use lorebooks to give characters long-term knowledge: world details, relationship history, recurring facts, and more.
- **Add voice** — Enable text-to-speech so your characters can speak their replies out loud.
- **Extend with JavaScript** — Power users can write custom JS scripts to modify how Tavo processes prompts, adds context, or formats responses.

## Where to start

If this is your first time using Tavo, the fastest path to your first conversation is:

1. Get an API key from a provider (Volink is the easiest starting point).
2. Enter the key in Tavo's API settings.
3. Pick a model and start chatting.
